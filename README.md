# Kunnskapsbygget

Desktop-app for NORMIA AI panel.

## Kjøre

```powershell
npm install
npm start
```

## Bygge

```powershell
npm run build
```

Appen ligger i `dist\win-arm64-unpacked\Kunnskapsbygget.exe`.

## Innhold

- `kunnskapsbygget-panel.html` – selve panelet
- `main.js` – Electron-oppstart
- `package.json` – prosjekt og bygg
- `manifest.json` / `sw.js` – PWA
- `icon-*.png` – appikon
